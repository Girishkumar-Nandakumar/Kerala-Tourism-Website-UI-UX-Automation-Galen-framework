🎯 Galen Framework Project — UI Layout & Responsive Testing
----------------------------------------------------------------------------------------------------------------------------------------------------------

🎯 Objective
-------------
To validate the visual layout, responsiveness, and cross-device consistency of the Kerala Tourism Website using the Galen Framework (Java) — a specialized tool for automated layout and responsive UI testing.

----------------------------------------------------------------------------------------------------------------------------------------------------------


✨ Project Highlights
----------------------

Focused on visual and responsive layout validation across multiple screen sizes

Implemented Galen Specs for element alignment, spacing, and consistency checks

Executed cross-browser and device-resolution tests using Selenium Grid integration

Combined with existing automation suite for holistic QA coverage (Functional + UI + Visual)

Generated detailed HTML reports highlighting layout deviations

🛠️ Tech Stack & Frameworks
---------------------------
| Category | Tools & Technologies | Description |
|-----------|---------------------|--------------|
|  Visual UI Testing	🖼 |  Galen Framework (Java)	  |  Specialized framework for responsive and layout testing across devices  |
|  Automation Engine	🧩 |  Selenium WebDriver	|  Powers browser automation and interaction for layout validation  |
|  Specification Language	📐 |  Galen Specs	|  Human-readable syntax defining expected layout rules (e.g., alignment, spacing, containment)  |
|  Test Runner	🧪 |  TestNG	|  Executes Galen tests and integrates with other automation modules  |
|  Build Tool	⚙️ |  Maven	|  Handles dependencies, compilation, and execution tasks  |
|  Report Generation	📊 |  Galen HTML Reports	|  Provides visual pass/fail summaries with screenshot evidence  |
|  CI/CD Integration	🔁 |  GitHub Actions	|  Runs layout checks automatically on commits and pull requests  |
|  Device Simulations	📱 |  Responsive Viewports	|  Tests layouts across desktop, tablet, and mobile breakpoints  |

🔍 Testing Scope
------------------

✅ Manual Verification
-----------------------
Verified UI responsiveness for Home, Destinations, Login, and Signup pages

Validated font, spacing, and image scaling consistency across breakpoints


🤖 Automated Layout Testing (Galen)
------------------------------------
Created .spec files defining layout expectations

Tested breakpoints: 1920×1080 (Desktop), 1024×768 (Tablet), 375×667 (Mobile)

Integrated with TestNG for structured execution and consolidated reporting

Captured screenshots of visual mismatches for analysis

🚀 Integration with Functional Tests
-------------------------------------
Combined Galen tests with existing Selenium / Selenide suites for unified regression runs

Validated both visual integrity and functional stability after UI changes
